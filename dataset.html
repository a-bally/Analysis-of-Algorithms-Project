Data Preparation

  • Loads delivery records from amazon_delivery.csv, indexed starting from stop 0.
  • Reads stop/order identifiers and latitude/longitude coordinates to build a pairwise distance matrix.
  • Selects the first N stops for each test tier and runs each configuration 7 times to average runtimes in milliseconds.
